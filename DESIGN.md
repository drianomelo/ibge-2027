# Visual system

## Direction

An independent study workspace for candidates preparing for fieldwork. The interface pairs the clarity of a question booklet with restrained cartographic details. The supplied brief governs the light surfaces, navy and cyan emphasis, direct language, and compact block selection. No institutional logos or visual identity are used.

## Layout

- Home: a split introduction with a short practice summary, followed by the eight CT block cards.
- Question flow: a narrow reading column, visible block progress, long-form alternatives, and a source-backed feedback panel.
- Result: a compact score summary with clear restart and return actions.
- Mobile: a single column, readable question text, and full-width result actions.

## Typography and detail

Use a system sans-serif stack so the static site works without font downloads. Keep body text around 0.88–1.05rem with generous line height. Headings use compact tracking and weight rather than display decoration. Keep corner radii between 8 and 14px; rely on a single border or a filled surface for separation, with no ornamental shadow.

Progress and score numbers use tabular numerals. Focus rings are visible, states use both color and text, and reduced-motion settings shorten transitions.
